> Portafolio web profesional desarrollado con ASP.NET Framework, que migra y moderniza mi portafolio anterior para presentar mis proyectos, habilidades y experiencia profesional con una arquitectura robusta, limpia y de alto rendimiento.

---

## 📌 Descripción del Proyecto

Este repositorio contiene el código fuente de mi nuevo portafolio personal. El objetivo principal de este proyecto es realizar la migración desde mi arquitectura/stack anterior hacia **ASP.NET Framework**, aprovechando el ecosistema de .NET para implementar mejores prácticas de desarrollo backend, una estructura escalable y un renderizado eficiente.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** C# / ASP.NET (MVC / Razor Pages)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap / Tailwind CSS
* **Herramientas & Entorno:** Visual Studio / VS Code, Git, GitHub / IA

---

## 🚀 Características Principales

* **Sección de Proyectos:** Galería interactiva con descripción, tecnologías y enlaces a código fuente/demos.
* **Sobre Mí:** Resumen profesional, habilidades técnicas (Hard & Soft Skills) y trayectoria.
* **Contacto:** Formulario integrado para envío de mensajes directos.
* **Diseño Responsive:** Adaptado para una navegación fluida en dispositivos móviles, tablets y escritorio.
* **Rendimiento Optimizado:** Arquitectura estructurada enfocado en tiempos de carga rápidos.
